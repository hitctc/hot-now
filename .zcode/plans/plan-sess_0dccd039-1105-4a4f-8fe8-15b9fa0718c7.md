## 改动目标

成品文章列表里，已推送草稿箱（`wechat_draft`）的文章代表周期已结束，要像已废弃文章一样弱化显示，但比已废弃稍强一点（表示正常结束，不是被废弃）。

## 改动文件（1 个）

### `src/client/pages/creative/FinishedArticlesPage.vue`

**1. 修改 `:row-class-name`（第 583 行）**

当前只判 `deletedAt` 和 `needs_review`，新增 `wechat_draft` 分支：
```ts
:row-class-name="(record) => record.deletedAt ? 'discarded-row' : record.status === 'needs_review' ? 'review-highlight' : record.status === 'wechat_draft' ? 'completed-row' : ''"
```
优先级：已废弃 > 待审核高亮 > 已完成弱化 > 普通。

**2. 新增 CSS（第 815 行 `<style>` 块内，放在 `.discarded-row` 规则之前）**

```css
/* 已推送草稿箱行弱化：表示文章周期已结束，比已废弃稍强一点便于区分 */
.completed-row td {
  background-color: #f7f7f7 !important;
  opacity: 0.65;
}
.completed-row .ant-table-cell-fix-left,
.completed-row .ant-table-cell-fix-right {
  background-color: #f7f7f7 !important;
}
```

**颜色对比**：
| 行类型 | 背景色 | opacity | 视觉强度 |
|---|---|---|---|
| 已废弃 `discarded-row` | `#f0f0f0`（较深灰） | `0.45`（很弱） | 最弱 |
| 已完成 `completed-row` | `#f7f7f7`（较浅灰） | `0.65`（稍弱） | 次弱 |
| 待审核 `review-highlight` | `#fffbe6`（浅黄） | 无 | 高亮 |

这样"已废弃"和"已结束"视觉同族（都是灰系弱化），但可区分（已废弃更深更透明）。
