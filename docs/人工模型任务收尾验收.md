# 人工模型任务收尾与验收记录

日期：2026-09-30。范围：文案／导语／日报请求幂等、取消与版本保护、剩余入口分类。现役合同见 [Hermes 自动化协作边界](./Hermes自动化协作边界.md)，本文记录本次计划、执行证据和未完成边界。

## 计划与成功标准

1. 提交前保存请求编号；响应丢失、原任务完成、近期历史淘汰、服务重启后重放仍找到同编号，不新增模型调用。存储失败不受理，跨文章或换参数重放拒绝。
2. 验证取消不强杀在途请求，保存结果后停止且不影响其他任务；版本变化不覆盖人工编辑；重开只观察原编号。隔离验收与生产真实模型验收分别记账。
3. 对 HTTP、CLI、Provider 和旧清单入口分类；共享业务入口使用唯一队列，不擅自改变图片配置、扩建队列或批量改历史文章。
4. 相关测试、完整构建、运行任务检查、标准发布和健康检查后精确提交推送；运行态、日志、SQLite 和临时结果不提交。

## 实现结果

- 文案、导语、日报请求支持时间戳＋随机编号。编号与操作对象及原始参数摘要绑定，映射和任务同文件原子保存；活动去重返回的编号也保存请求别名。终态保留脱敏收据，不包含正文、提示词或检查点。
- 收据保留 30 天，过期编号拒绝重放。浏览器禁用存储不能保证跨刷新恢复；时钟超前超过五分钟等偏差可能导致请求校验拒绝。自动开关关闭不妨碍找回已存在编号，不允许新开自动任务。
- 日报 HTTP 立即受理，GET 只查询编号；正式 CLI 提交常驻 API。素材快照、分类结果及成功封面可恢复，页面持久保存编号、关闭停止观察、重开恢复观察、网络失败退避。
- 导语保存生成时版本，冲突终止回写、保留结果，不重读新稿合并。旧检查点缺少原版本则禁止回写；同一文本已交付时重复回调幂等成功。旧同步响应兼容也校验原版本。
- 取消正文已交付的排队任务保持素材 done，重复取消终态不再次回退状态。下一次文本请求前检查取消与冷却，冷却归队释放资源，不持有租约等待五分钟；在途请求仍不强杀。

## 验收证据

- Hermes 11 个相关测试文件共 **85 项通过**；模型调用、租约和文件目录统一隔离，不运行真实模型或生产 worker。
- HotNow 相关 **29 项测试通过**；完整客户端／服务端构建及客户端类型检查通过。
- 实际 TCP/HTTP 与线程取消验收：使用现役取消和结果业务函数、实际队列与持久化、模型替身；先收到 cancelling，替身返回后保存结果并转 stopped，另一任务保留；重复取消保持终态。此适配器不是生产 API 进程，不代表真实模型取消已验收。
- 实际 HotNow HTTP 回调与临时 SQLite：人工编辑后原版本回调返回 409，缺失版本返回 400；手工正文不变、导语不入库，临时库完整性检查通过。
- 请求丢失恢复：原任务执行一次后清空隔离历史、重建并恢复队列；相同请求仍返回 done 原编号，假模型调用计数保持一次。
- 浏览器逻辑：提交网络失败保留请求编号，重新加载模块仍读到持久编号；终态后新主动操作使用新编号，普通保存和 GET 不添加编号或隐式重试。
- 用户此前已明确验证生产人工插队和被插队任务自动续跑，未为重复证明这两项额外投递任务。

## 入口审查及保留决定

具体入口表以边界文档为准。旧图片模块虽包含文本生成工具，现役 regen-cover／regen-inline-image HTTP 路径只使用已有提示词，缺失则失败，不回退调用写作模型；图片 API 是独立 Provider，保持配置。codex-manual HTTP 创建清单，不据此宣称其外部消费端已统一。维护 dry-run 仍可能调用文本模型，不是完全离线预览。

当前新增请求合同只覆盖门户文案、导语、日报；素材创建、写作提交和旧图片请求沿用原去重范围，未冒称全部入口均具备本文案终态幂等。正式 CLI 转入队列但未增加跨 CLI 重启的请求编号观察合同。

审查采用本轮差异的规范／需求两轴自审，重点检查同文件原子性、请求别名、历史淘汰、版本回写、取消终态和恢复 worker 类型。本会话没有双子智能体工具，未执行或宣称独立双智能体审查。

## 仍未完成的生产验收

### 待用户浏览器操作清单

以下均为待验收，隔离测试已通过不代表生产现场通过。智能体没有可用的已授权浏览器操作能力时不再反复连接、登录或重启；完成可执行任务后提醒用户操作。后续根据用户实际反馈记录结果，不自动勾选。

- [ ] **真实模型取消**：在长文或短内容成品详情发起一次模型生成，等队列显示执行中后取消该任务。通过标准：先显示取消中，在途请求结束后停止后续步骤；已生成结果保留且可只读查看，其他任务不受影响。没有已生成结果时不要求凭空出现产物。
- [ ] **现场版本冲突**：用非正式发布稿的测试成品发起导语生成，在生成期间修改并保存正文。通过标准：旧版本结果停止回写并保留，人工保存的正文不变，旧导语不作为新结果写入。必须在模型完成前保存编辑，否则不能算冲突验收。
- [ ] **手机刷新恢复**：在手机 `/daily-digest` 提交一次日报任务，受理后刷新或离开再重开页面。通过标准：观察原任务编号，不新增同一操作的模型任务；完成或取消后显示对应终态。文案任务可在成品详情按相同步骤验证。

上述操作会调用真实模型，日报可能沿现役流程产生外部推送；验证前选择合适的测试数据和时段，不使用重要稿件，不连续投递任务。反馈请包含操作类型、任务编号、观察到的结果；无需提供凭据、Cookie 或 token。
