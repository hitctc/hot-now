# 写作质量上线后首轮观察

## 结论

新短稿相对更新前同类样本，最明显的变化是从“事实之后必须补一段意义、建议或警示”转向直接报道，空泛论述减少，部分简单消息能较早收住。这个方向符合准确、切题、清楚、自然的目标，但不能据此宣称整体质量已经稳定提升：泛化边界句、内部素材口径和附属文案的无据判断仍存在。

本轮没有新长文，不能对长文改善作结论。不同素材的前后观察也不是同素材、同模型的严格对照。

## 实际区别与例子

### 1. 意义段明显减少，简单消息可以报道后停止

旧稿 #4101 报道泰国王后执飞行程后，补上“一次具体行程不能说明泰国王室出访模式已经改变”，继续解释不足以作政治外交判断。素材本身没有提出这种宏观结论，这一段在反驳一个并未出现的判断。

旧稿 #4102 报道三名中国女性获表彰后，又写“不能直接等同于这些经验已经形成普遍效果或可复制模式”，把荣誉新闻扩成经验推广讨论。

新稿 #4139 报道深圳禁鸣措施，保留11月1日起、全天、全市道路、5年有效期及紧急情况边界后就结束，没有再解释政策“真正的意义”或泛化成给读者的行动建议。新稿 #4132 则把篇幅用于车型、预售价和上市时间，没有硬加消费建议。

**判断：少的是脱离新闻任务的外延讨论，不只是少了字。** 这些是不同事件的同类新闻比较，不是同一事实包的改写效果证明。

### 2. 技术消息更集中于“发布了什么、在哪里可用”

同为 Step 5 Preview 相关消息，旧稿 #4105 在权重发布和参数之后，用一段讨论“实际使用价值”“部署成本”“开放权重不等于效果已经被广泛验证”。新稿 #4118 更集中于 FeatherlessAI 上线、FP8、架构与成本数据，并保留数据出处。两稿报道动作不同，不能直接比较信息覆盖率，但能看到论述重心的变化。

新稿 #4133 的 Code Review 消息仅报告结束研究预览及 Team/Enterprise 开放范围，没有从一条发布信息扩写成团队采用建议。其末尾“标志着该功能进入正式可用阶段”仍重复前文，可以删减；短稿不等于完全没有重复。

### 3. 关键限定可以保留，不需要一律删掉提醒

新稿 #4115 区分已开放的创作界面/MCP/CLI与后续才推出的HDR/API；#4119 同时保留两种 harness 下的97.5%与49.8%及对应成本；#4127 区分检察机关指控与法院认定；#4140 保留一审、上诉与家属说法的归属。

这些限定承担事实职责，应保留。不能把“没有评论”当作目标，也不能把所有谨慎表达都算套话。

### 4. 仍有泛化边界句与内部口径

- #4117 在说明 Diffusers 接入后，追加“具体模型规格、效果和使用成本仍需以官方发布内容为准”。边界表达较宽泛；该篇审改回退，实际保留的是审改前版本。
- #4136 报道 SGLang 接入后，又提醒“接入信息本身不代表模型在所有环境中的性能、成本或可用性都已得到验证”。这类全场景免责声明仍像固定收尾，不是本条消息必须回答的问题。
- #4135 正文出现“但素材未提供具体对比数据”。这暴露了编辑/核验输入的内部口径，而不是面向读者的直接表达。该篇审改也回退了，不能把问题误说成审改版本已经采纳。
- #4114 的 BPB、held-out、FLOPs，以及多篇中的 checkpoint、harness 等术语没有最小解释。信息更集中，不代表普通读者理解门槛已经降低。

**判断：不是套话消失了，而是强制意义段少了；泛泛提醒和少数内部口径仍未收干净。**

## 审改、降级与失败实际发生了什么

- 在28篇未混入后续正文差异的新稿中，25篇审改回执为 `corrected`；3篇为 `fallback`，分别为 #4117、#4121、#4135，回执原因分别记录审改后质检88、92、82分未通过。它们保留审改前版本，不是未产出文章，也不能仅凭分数推断是哪项门禁失败。
- 14篇旧主样本中，11篇 `corrected`、3篇 `fallback`。新旧来源构成与事件不同、样本小，不用这两个比例证明审改质量或效率改善。
- **10篇新主样本发生交付恢复/附属文案降级**：#4113、#4114、#4116、#4119、#4123、#4126、#4128、#4129、#4133、#4137。记录均包含丢弃评论和作者拓展，部分还回退导语或其他字段。不能将“最终没带出这些判断”误说成生成阶段从未出现问题。
- 例如 #4116 的附属文案产生“门槛一下低了不少”“研究和二次开发更方便了”；#4133 产生“开始成为团队协作流程的一部分”；#4126 产生“降低落地门槛”“降低试验成本”。素材没有支持这些已发生效果，交付核验进行了降级。这是现役保护机制的证据，也说明附属文案仍有固定拔高倾向。
- #4128 的交付恢复记录还出现“文章摘要里没有展开”“摘要能确认的是”等过程口径，最终正文已换成面向读者的描述。#4135 仍残留“素材未提供”，说明保护并非对所有同类表达都有效。
- 两个未成稿的阻断任务分别涉及新标题改变事件确定性（素材 #27804）和正文时间顺序错置（素材 #27880）。一个失败任务（素材 #27816）是质检回执 `consistent=true` 但 `conflicts` 非空的格式矛盾。不能把它归类为素材被判不实或笼统的模型不可用。

## 后续建议

1. 保持现有直接报道方向，不恢复固定评论比例、必有建议或强制意义段。
2. 如要继续改，优先处理有证据的问题：与本条消息无关的全场景免责声明、内部“素材/摘要”口径，以及导语/评论/作者拓展的无据效果判断；不新增模型轮次、评分体系或禁词清零目标。本轮没有实施这些改动。
3. 等正常长文任务产出后另补观察；不为凑样本额外触发写作。短稿继续按来源与任务复杂度分层，不只挑最好或最差的新稿。
4. 后续比较继续记录原任务、成品、素材和审改/回退信息，排除后续编辑；如需证明因果改善，再单独设计同素材对照，不把本轮观察包装为严格实验。
