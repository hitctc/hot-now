# 创作外部智能体接口

> 本文是外部智能体与 HotNow 创作工作台交互的当前 HTTP 契约。路由实现和测试优先于本文；接口变更必须同批更新本文。

## 1. 接入约定

- 服务地址：`https://now.achuan.cc`
- 健康检查：`GET /health`，成功返回 `{ "ok": true }`。
- 创作接口使用请求头 `x-creative-token: <token>`。
- 调用方从自己的密钥管理或运行环境注入 `CREATIVE_API_TOKEN`；不得读取他人本机 `.env`、在 prompt 中硬编码 token，或把 token 写入仓库。
- 所有请求使用 JSON 和 UTF-8；遇到 `5xx` 可退避重试，`4xx` 应修正请求后再重试。

## 2. 素材入库

### `POST /api/creative/source-items`

必填字段：`externalId`、`collectorAgent`、`title`、`url`。

常用可选字段：`sourceName`、`summary`、`fullContent`、`author`、`coverImageUrl`、`tags`、`language`、`wordCount`、`contentType`、`score`、`publishedAt`、`collectorTimestamp`、`trendScore`、`trendBreakdown`、`direction`。

`writingStatus` 仅为短内容兼容字段。新建 `direction=article` 长素材时，服务端会强制写为 `pending`，调用方不能传 `ready` 绕过账号适配门禁。

```json
{
  "externalId": "hn-42134567",
  "collectorAgent": "example-collector",
  "title": "示例标题",
  "url": "https://example.com/article",
  "summary": "可选摘要",
  "direction": "article"
}
```

- 相同 `externalId + collectorAgent` 幂等：新记录返回 `201`，已存在记录返回 `200`。
- 重复推送只补充库中为空的字段，不覆盖已有非空值。
- 长素材创建后会立即加入 SQLite 账号适配队列；自动范围只覆盖入库 72 小时内的素材。历史素材不会因此批量回填。
- 可用状态：`pending`、`ready`、`queued`、`writing`、`done`、`skipped`、`excluded`、`failed`。
- 常见失败：`400 missing-required-fields`、`401 invalid-token`、`503 creative-api-token-not-configured`、`503 database-not-available`。

## 3. 查询待处理素材

### `GET /api/creative/source-items`

常用查询参数：

| 参数 | 说明 |
| --- | --- |
| `writingStatus` | 按素材状态筛选，例如 `ready` |
| `collectorAgent` | 按采集智能体筛选 |
| `sourceName` | 按来源名称筛选 |
| `search` | 搜索标题和摘要 |
| `page` / `pageSize` | 分页，默认由服务端处理 |
| `direction` | 按长文或短内容方向筛选 |

生成文章前应只处理 `linkedArticleId === null` 的素材，避免重复产出。

## 4. 获取 AI 新讯候选

### `GET /api/creative/feed/ai-new?minScore=80`

返回尚未入库、评分不低于 `minScore` 的 AI 新讯候选，默认 `80`，最多返回 50 条。`fullContent` 为 `null` 时，调用方需要自行抓取原文；随后使用素材入库接口推送，`url` 使用返回的 `canonicalUrl`。

## 5. 推送成品文章

### `POST /api/creative/finished-articles`

必填字段：`sourceExternalId`、`collectorAgent`、`contentMarkdown`。

```json
{
  "sourceExternalId": "hn-42134567",
  "collectorAgent": "example-collector",
  "contentMarkdown": "# 示例文章\n\n正文",
  "thesis": "可选核心观点",
  "titles": ["可选标题"],
  "summary100": "可选摘要"
}
```

- 服务端按 `sourceExternalId + collectorAgent` 关联原素材，并在成功后把素材状态改为 `done`。
- 已存在关联成品时默认返回 `409 article-already-exists`；明确传 `allowDuplicate: true` 才允许重复创建。
- 常见失败：`400 missing-required-fields`、`401 invalid-token`、`404 source-item-not-found`、`409 article-already-exists`。

## 6. 回写素材状态

### `POST /actions/creative/source-items/:id/writing-status`

请求体至少包含 `writingStatus`。使用 `x-creative-token` 时可由外部智能体调用；管理端也可使用已登录会话执行。

```json
{ "writingStatus": "failed", "stopStep": 3, "stopStepName": "事实核验", "stopReason": "原文不可访问" }
```

- `skipped` 和 `failed` 可附带 `stopStep`、`stopStepName`、`stopReason`；三项出现时必须同时完整提供。
- 状态值与素材入库接口一致。

## 7. 账号适配自动化状态

以下接口只给 HotNow 已登录管理端使用，不使用外部 `x-creative-token`：

- `GET /api/creative/automation/status`：返回评估/写作开关、待处理数量、上海自然日已投递自动写作数（上限 10）和最近错误。
- `POST /api/creative/automation/evaluate/enabled`：请求体 `{ "enabled": true }`，仅暂停或恢复自动评估。
- `POST /api/creative/automation/write/enabled`：请求体 `{ "enabled": true }`，仅暂停或恢复自动写作。

关闭自动开关不会取消既有任务，也不会影响人工评估或人工写作。任务和重试历史在 HotNow SQLite 中保留 30 天；评估结论永久保存在素材记录。

## 8. 溯源协作

- HotNow 管理端发起：`POST /actions/creative/source-items/:id/trace`。
- 外部溯源服务完成后回写：`PUT /api/creative/source-items/:id/trace-results`，请求体为 `{ "results": [...] }`，鉴权使用 `x-creative-token`。
- HotNow 调用外部溯源服务时使用 `HERMES_API_BASE_URL` 与 `HERMES_API_TOKEN`；该外部服务的内部接口契约由 Hermes 侧维护。

## 9. 最小工作流

1. 先请求 `/health`。
2. 从外部来源或 AI 新讯 feed 获取候选。
3. 调用素材入库接口，保留稳定的 `externalId + collectorAgent`。
4. 新入库长素材由 HotNow 异步完成账号适配：高适配自动排队，中适配转 `ready` 等待人工，低适配和信息不足转 `excluded`。
5. Hermes 只接受 HotNow 已投递的任务；写作完成或失败后按实际状态回写素材。
