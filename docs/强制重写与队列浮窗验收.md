# 强制重写与队列浮窗验收

## 范围

- 短素材写作按钮完整显示并可换行，不扩大列宽或新增写作方式。
- 全局文章队列贴齐右下角，低于现役草稿推送浮窗及其倒计时。
- Hermes 内容阻断记录可确认后新建人工强制稿，保留原任务和旧稿；核验/质检仍运行，未通过项持续留痕。模型、额度和存储等技术错误不放行。
- 长短成品保留“人工强制重写 · 待人工审核”、原阻断及本次风险；不新增独立审核通过操作。仅在原草稿推送浮窗完成一次风险确认，推送后标记不清除。
- 数据库、队列、任务结果等运行文件沿用原验证快照及源码白名单流程，不清理、不纳入功能提交。

业务合同见[Hermes 自动化协作边界](./Hermes自动化协作边界.md)。本记录不替代现役合同。

- `tests/client/writeQueueRecentResults.test.ts`：按钮不截断、阻断记录资格、确认后提交原编号。
- `tests/client/articlePushFloatWidget.test.ts`：右下位置和层级、普通稿不加确认、强制稿在原浮窗确认一次、五秒倒计时。
- `tests/client/modelTaskRequest.test.ts`：强制重写编号在响应丢失和重开后复用。
- `tests/server/forcedRewriteDelivery.test.ts`：长短新稿保留原稿、风险摘要及交付重放不覆盖。
- `tests/server/forcedRewriteProxy.test.ts`：会话鉴权与确认意图转发，排除伪造素材/风险。
- `tests/creative/manualForcedRewrite.test.ts`：风险标记、状态限制、重复交付恢复。
- `tests/wechatMp/forcedDraftPush.test.ts`：服务端风险确认和内容条件校验。
- Hermes `tests.test_manual_forced_rewrite`：内容阻断资格、原素材关联、长短内容风险交付、恢复与技术错误停止。
- Hermes 原长短写作、队列恢复和合同测试：普通门禁及唯一队列保持不变。

定向用例、客户端类型检查和服务端编译检查已通过；末轮 Hermes 隔离测试 95 项通过。当前没有独立子智能体工具，已按需求/规范两轴自审并修复空证据索引误确认与恢复风险丢失，不冒称独立审查。

Hermes 使用 `scripts/run-isolated-tests.py` 的临时源码副本、空 HOME 和模型替身，禁止访问运行产物或真实模型。测试通过不能记为生产真实稿件验收。

## 待用户浏览器验收

当前工具不能直接操作已登录浏览器；以下项目保留待办，不以构建或健康接口代替。

1. 打开 `/creative/short-source-items`，电脑和手机横向滚动到写作列：按钮“写短内容”“写作中”完整显示，必要时换行，无省略号。
2. 展开右下文章队列，确认折叠/展开、刷新和取消仍正常；推送成功的五秒倒计时浮窗应位于队列之上。
3. 在事实/质检内容阻断记录点击“强制重写”：先显示原阻断和放行风险，取消不投递；确认才进入人工队列。该动作会消耗真实模型额度，验收时仅选择用户愿意重写的任务。
4. 新成品列表标记及其悬停说明、详情审核标记保留原原因和本次未通过项；原任务及旧稿仍可查。
5. 强制稿不要求先点“审核通过”或“标记可推送”。补齐标题、正文、封面且实际发布文案通过[发布语境门禁](./发布稿语境验收.md)后点“推送草稿箱”：只在原浮窗展示风险，确认一次后开始；取消/关闭不推送。风险确认不豁免语境污染。
6. 草稿推送会写微信公众号草稿箱，仅在用户确实需要时执行。完成后再读成品，状态可变为已推送，但风险标记和原因不清除；普通合格稿仍直接推送。

真实模型与上述浏览器验收：待用户反馈。
