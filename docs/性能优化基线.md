## 2026-10-03 完整实施与验收

### 实现和保留决定

- W01–W03：以 `31861c0` 为前置点，在独立源码副本重建基线；实际组合式函数测试复现内容请求旧成功/失败/收尾覆盖，复用 latest-request guard。素材封面/详情读取按当前身份处理；详情与素材首次有效属性挂载会立即初始化。
- 组件库只注册现役模板使用的组件族，保留主题、样式提供器、子组件和函数式提示/确认出口。编辑器与素材弹窗首次打开才下载，关闭不直接销毁外层；加载中可关闭，下载失败需要确认未保存内容后重载页面再打开。Chrome 故障注入证明单纯重建加载器仍会复用失败模块缓存，因此不自动重载、不自动重放业务操作。
- W04：统计、Codex 队列/消耗及自动化配置的周期读取隐藏暂停、恢复刷新、单飞和卸载收尾；自动化配置保留已有专用单飞、故障快照与 dirty 输入保护。未发现 `usePipelineStatus` 或 `MonitorPlatformStats` 的现役消费者，不把它们算作线上请求开销，不删除兼容入口。
- W05：手机仅编辑时跳过不可见主题 HTML 和 Markdown 回退解析，打开预览时使用最新稿。Chrome 两帧观察的输入时间仍约33毫秒，没有可重复的可见输入收益证据；不加全文缓存、worker 或额外防抖，也不宣称输入提速。
- 核心保存门禁复现已有缺陷：父页关闭时清空文章，5秒防抖前的最新稿未保存。现在原保存队列按文章编号保留各稿的最新版，仍严格串行；真正关闭等待当前稿确认，失败保留编辑器重试。切换前按原编号提交，响应不串写另一文章，显式保存只清理当前文章的失败稿。没有新建 Hermes 业务队列或改正文/标题处理。
- W06：队列展示 SQL 进入 `creativeWriteQueueDisplayRepository`；相同外部标识去重、每400项批量关联，歧义仍不映射，成品关联优先。继续使用现有克隆后的缓存快照，不新造缓存/状态机，不改全量日期带、软删除统计、旧日志和历史上限。
- W07：057迁移只增加素材日期与成品历史的原始列覆盖索引；不使用会限制历史日期输入的日期表达式索引。原成品分页索引已命中、文章日统计约0.83毫秒、推送统计约0.03毫秒，保留；不新增统计缓存，不改变新鲜度。
- W08：固定20组件的状态/请求迁至同目录具名组合式函数，仅返回展示、具名模板引用和明确公开成员。`creativeApi` 保留兼容出口，按五个领域拆分；CSS六片段按原顺序拼接，仍唯一 `/assets/site.css`。全量扫描没有超千行源码/测试。文章控制器超过800行已检查，剩余内容是同一编辑器协调，保存/图片/发布已有专用模块，不为行数再拆。
- W09：公开生产资源已有 gzip、ETag、Vary 和一年不可变缓存；单次 ALPN 为 HTTP/1.1，不能证明所有链路或源站缺口。不修改共享 Nginx，不重复实现缩略图/原图按需加载。

## 2026-07-31 列表连接阻塞复盘

浏览器曾记录成品文章第 `21` 页请求总耗时 `36.51s`，其中连接等待（Stalled）为 `36.28s`，服务端响应等待只有 `229.40ms`。相同请求在生产服务器连续执行为 `65.5～129.1ms`，20 路并发最慢约 `1.29s`，因此不是列表接口执行了 36 秒。

根因证据：

1. 截图中第 `21` 页之前访问过第 `6` 页；该页有 `17` 张同域封面，总量约 `35MB`，中位数约 `2.08MB`，全部超过 `1MB`。
2. 单张封面通过公网下载曾约 `4.3s`；生产站只启用了 HTTP/1.1，大图会占用有限的同域连接，使后续 XHR 在浏览器连接池等待。
3. 写作队列状态代理同期出现过 `6.7s`、`8.9s` 和 `10.8s` 慢请求，进一步占用连接。
4. 勾选“显示已废弃”后，迁移 `46` 的部分索引不适用，查询需要临时排序；这只贡献约 `62～65ms`，属于次要瓶颈。

本批修复：

- 本地图片增加最大边长 `96px`、质量 `72` 的 WebP 缩略图。新图片上传时生成，历史图片首次访问时生成并原子缓存；失败只显示占位，不回退下载原图。
- 成品列表只加载缩略图，增加懒加载、异步解码和低请求优先级，点击预览时才读取原图。
- 四个核心创作列表在新请求开始时取消旧请求，只有最后一次结果可以更新页面。
- 写作队列状态使用服务端单飞和 `15s` 新鲜缓存，Hermes 最多等待 `3s`；失败时返回五分钟内最近一次成功状态并显示延迟标记，页面隐藏时暂停轮询。
- 迁移 `47` 增加覆盖全部成品的方向/置顶/创建时间索引；生产快照副本迁移约 `1.06s`，`quick_check=ok`，包含已废弃文章的查询不再临时排序，中位数约 `0.021ms`。
- Nginx 模板启用 HTTP/2，并提供备份、`nginx -t`、失败回滚和 reload 的一次性脚本；生产切换必须由具备 sudo 权限的用户执行。
