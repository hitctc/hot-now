# 成品详情折叠验收

## 当前行为

长、短成品共用详情组件。读者评论（含作者回复）、作者拓展、配图与封面（含代码图片）、配图提示词、相似度检测、写作流程及正文配图分别提供折叠/展开，首次默认展开。本地存储按长/短内容和区块区分，不按文章编号区分，不跨设备同步。无类型的历史稿按长内容处理。折叠只隐藏展示内容，不修改成品或取消生成任务；标题区的复制和生成按钮保留。存储不可用时仍可在当前组件内操作。

配图与封面折叠指令作用于包住网格及封面提示词的实际容器：图片预览组件是多根节点，不能直接接收隐藏指令。回归测试使用真实预览组件，不再用单根容器替身。任一比例 `stale` 时，标题后显示“内容已变化，建议重新制作”，折叠和制作中均保留，直到实际状态更新。

移动端（≤768px）顶部将全文标题、紧凑元信息与完整素材链接分层。区块标题、候选标题/导语和操作区分开；评论、提示词、正文主题/工具也不再挤占文字宽度。不截断全文、不隐藏字段；除合并图片区外，桌面保持原布局。长、短成品均将代码图片与封面候选合并为「配图与封面」，按地址去重，选封面仍使用原索引。候选每行三列，等高缩略图完整展示各比例，当前封面与选择按钮不覆盖缩略图。预览预算不超过440px/屏高60%，单图不超过160px/预算一半；额外候选及按钮自然换行，不裁切、不新增内部滚动，由详情统一滚动。上传、制作/重做及封面提示词生成常驻顶部。

配图提示词收起用实际容器的隐藏指令，保留内部未保存草稿与复制/保存/脏状态事件。移动端“复制原标题”等独立按钮左对齐；普通正文主题行不换行，横向滚动选择，下面普通工具区的“复制原文”和“复制纯文本”隐藏。桌面保留这两个入口，专注工具与全屏预览工具不受本次调整影响。

相似度区块包含“未检测”也可收起，手动文章仍不展示该区块；写作流程只收起步骤列表，中止原因和总览状态常驻。正文配图收起图片和提示词，标题区生成/上传动作保留，只读模式也可折叠。生成的代码图片标签使用紫色描边标签组件，支持长文字自然换行。

四张创作表格的来源统一移入标题列下方；成品来源后以括号显示已有质检分或“未评分”，短成品取消重复质检列。素材原评分及账号适配保持原口径，短素材的榜位移到标题列来源下方。既有领域标签、素材/成品关联保留，关联素材标题可完整换行。

长短详情的当前封面使用3px翠绿外框、浅绿整卡底和深绿白字实色标识，搭配26px白底勾选圆章；标识位于缩略图下方，不覆盖图片，也不依赖悬停，只读时同样保留，待选择封面使用常驻紫色设置按钮。底栏显示已有成功推送次数，零次不带括号，禁用时同样显示。推送成功后只更新同篇详情的服务端次数，不覆盖继续编辑的正文；关闭或切换后忽略旧刷新响应，刷新失败明确提示，不在点击或失败时累加。

短稿发布正文在初始化、显式保存及推送渲染时补一个空行和“跪求点赞、关注。”，自动替换末尾旧文案“跪求点赞、关注，谢谢你。”，重复的新旧结尾合并为一个；仅标题/封面占位及空稿不补，素材原文、AI草稿和长文不追加。不批量回填历史；进入编辑器后由原保存流程落盘，列表直接推送仅补渲染内容，不触发额外保存。实时预览、五个公众号主题及推送共用「大字宣言海报」：36px、900字重的“跪求”独占标题带，珊瑚粉切角与深海蓝底板形成强对比，下方26px“点赞、关注。”使用粗划线，直角轮廓与错位实色投影增加层次；不再使用小字手写落款、小字章或橘色侧边，不随主题变化。全文仍为原文案，不增添提示文字或假链接；全部内联排版，不依赖图片、外部字体、定位或弹性布局。

## 浏览器验收待办

- [ ] 关闭后打开另一篇长稿、刷新再打开，确认三个区块分别沿用选择；展开后重复操作，确认展开状态也保持。
- [ ] 在 `/creative/short-finished-articles` 重复以上步骤，确认首次默认展开、短稿设置不改变长稿设置。
- [ ] 在手机和桌面确认按钮可见、可点击，展开后图片预览和复制保持可用。

- [ ] 任一代码图片已过期时，折叠后标题旁仍能看到重做提示；重新制作成功后按实际状态消失，图片预览继续可用。
- [ ] 在 320、375、390、430 像素宽度检查：长标题、导语、标签、评论和提示词使用完整宽度，区块操作独立在下方且自然换行，正文主题与编辑工具分组，无横向溢出或按钮重叠。
- [ ] 手机及桌面、长短详情仅展示一组配图与封面，三比例按高度完整缩小且不重复；点击预览、设封面、下载及复制地址正常。额外上传图继续换行，不丢候选或错选原索引；图片区无内部滚动，操作由详情整体滚动到达。
- [ ] 制作/重做及上传、生成提示词在折叠后仍可操作；过期提示常驻，提示词草稿不丢失。
- [ ] 手机及桌面查看短稿结尾：“跪求”独占第一行，字号和字重高于“点赞、关注。”，不能再退回小字。珊瑚粉标题带、深海蓝底板、粗划线和错位投影有清晰层次；320px宽度下无横向溢出、裁切或标点错位。实时预览和五个主题效果一致，复制原文仍为准确文案。
- [ ] 保存重开后旧结尾被替换且仅有一次；公众号中确认大字、两层排版及标点，阴影或切角渐变未保留时，实色和字体仍清晰。推送样式在用户下次正常推送时确认，不为验收额外推送。
- [ ] 桌面检查顶部与候选操作保持原布局，全文、复制、编辑、生成和发布选择行为不变。

- [ ] 配图提示词独立折叠，重开/刷新恢复长短内容各自选择；编辑草稿收起后展开仍保留，保存与复制正常。
- [ ] 手机“复制原标题”左对齐；多个主题保持单行，可横向滚到末项并选择；下方普通工具区不再显示两项复制按钮，其他操作保留。

- [ ] 代码图片标签有独立边框、底色及圆角，长文字可换行，在明暗主题均可辨认。

- [ ] 手机和桌面查看四张表，只看标题列即可看到已有标题、领域标签、关联素材/成品及来源；长关联素材标题完整换行，短素材保留首次榜位，独立来源列不再显示。
- [ ] 成品来源后显示 `（质检分：N）` 或 `（未评分）`，真实零分不消失；素材仍显示选题分/原基础评分，不误标成品质检。
- [ ] 手机和桌面能一眼区分当前发布封面：粗翠绿外框、浅绿卡片底、深绿白字实色标识及大号勾选圆章均清晰，文字自然换行，不遮图或溢出。切换封面后仅新封面高亮；长短内容及只读模式一致，重复候选只显示一个标识，图片预览与三列布局不变。
- [ ] 已推送稿详情显示 `推送草稿箱（N次）`，未推送稿不带次数；禁用门禁仍生效。用户确需再次推送时，成功后次数更新，推送期间继续编辑的正文不被覆盖；失败不增加次数。

- [ ] 手机和电脑打开短稿，发布正文末尾有一个空行及准确结尾文案，预览一致；连续保存/关闭重开不重复，AI草稿及长文不追加，空白人工稿不因结尾通过正文门禁。未经实际发布需要不额外推送。

通过标准：各区块互不影响，长短类型互不影响；收起与展开均能恢复，过期提示不被隐藏，不丢正文、图片或操作。移动端分层减少挤压造成的换行，保留文字本身必要的自然换行。

## 文章队列布局与待验收

手机和电脑共用规则：入口及展开面板贴齐右边缘，右侧无圆角；关闭和刷新均为 44×44 像素点击区，图标居中。当前任务取消按钮左对齐且只操作当前任务编号，不改变等待安全取消的语义。队列数据、轮询、状态记忆和其他业务动作不变。

- [ ] 手机与桌面确认收起/展开均贴齐右边缘，无右侧圆角；关闭、刷新易于点击。
- [ ] 当前任务取消靠左，点击仍显示安全取消反馈；刷新不改变选中任务，关闭只收起队列。
