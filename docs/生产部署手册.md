# 生产部署手册

> 本文只记录当前单机部署方式。发布脚本、部署模板和实际服务器配置优先于本文；历史上线过程通过 Git 历史追溯。

## 1. 当前部署模型

- 域名：`https://now.achuan.cc`
- 应用：`systemd` 服务 `hot-now`
- 反向代理：Nginx
- 代码目录：`/srv/hot-now/app`
- 共享状态目录：`/srv/hot-now/shared/data`
- 生产环境变量：`/srv/hot-now/shared/.env`

日常发布由本地 `/scripts/deploy-prod.sh` 执行：**本地先运行 `npm run build`，再通过 rsync 上传源码和 `dist`；服务器只安装 production 依赖、重启服务并做健康检查。**

## 2. 首次部署

1. 在服务器安装 Node.js、npm、Nginx、rsync 与项目运行所需系统依赖。
2. 创建 `/srv/hot-now/app`、`/srv/hot-now/shared/data`、`/srv/hot-now/shared/.env`；共享目录和 `.env` 不由发布脚本覆盖。
3. 在生产 `.env` 设置应用凭据、SMTP、数据库与报告目录覆盖项，以及实际启用的 Hermes、创作 API、AI 时间线配置。
4. 安装仓库模板：
   - `deploy/systemd/hot-now.service`
   - `deploy/nginx/hot-now.conf`
   - `deploy/sudoers/hot-now-systemctl`
5. 使用 `visudo -cf /etc/sudoers.d/hot-now-systemctl` 校验 sudoers；部署用户只应拥有 `hot-now` 的 restart/status 免密权限。
6. 执行 `nginx -t` 后 reload Nginx，并确认云侧安全组和本机防火墙放行 `80/443`。

生产路径覆盖项至少包含：

```bash
HOT_NOW_DATABASE_FILE=/srv/hot-now/shared/data/hot-now.sqlite
HOT_NOW_REPORT_DATA_DIR=/srv/hot-now/shared/data/reports
PUBLIC_BASE_URL=https://now.achuan.cc
```

## 3. 日常发布

在本地创建不入库的部署配置：

```bash
cp .deploy.local.env.example .deploy.local.env
```

填入 `HOT_NOW_DEPLOY_HOST`、`HOT_NOW_DEPLOY_USER` 等目标信息后执行：

```bash
./scripts/deploy-prod.sh
```

脚本按以下顺序执行：

1. 本地运行完整构建；
2. 在覆盖代码前，对生产数据库做只读检查并创建可恢复快照；
3. rsync 同步代码和已构建的 `dist`，但不覆盖 `.env`、`data`、`.git`、`node_modules`；
4. 停止服务释放内存，在服务器执行 `npm ci --prefer-offline --production`；
5. 通过 `sudo -n` 重启服务，并轮询 `http://127.0.0.1:3030/health`。

脚本失败时不要手工覆盖共享目录；先保留输出并检查最近快照、`systemctl status hot-now --no-pager` 与 Nginx 错误日志。

## 4. Nginx 与静态资源

`deploy/nginx/hot-now.conf` 负责 HTTPS 反代、`80 -> 443` 跳转，以及 `/client/assets/` 下 Vite hash 资源的直出、gzip 与长缓存。更新模板后必须执行：

```bash
sudo nginx -t && sudo systemctl reload nginx
```

如服务器仍使用旧的 HTTP/1.1 配置，可在部署完成后按 `scripts/enable-nginx-http2.sh` 的说明启用 HTTP/2；脚本会先验证 Nginx 配置。

## 5. 数据与回滚边界

- 发布脚本不触碰 `/srv/hot-now/shared/data` 与 `/srv/hot-now/shared/.env`。
- 部署前快照位于共享数据目录的 `recovery-backups/` 下；回滚前先确认快照和当前服务状态。
- 本地排查生产数据使用 `scripts/pull-prod-data.sh` 和 `scripts/dev-prod-sync.sh`，不得让本地开发直接连接生产 live 数据。
