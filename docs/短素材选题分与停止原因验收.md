# 短素材选题分与停止原因验收

## 本轮目标与边界

用户确认短素材只保留实际入选的选题评分，停止无依赖的通用基础/爆文评分，逐篇展示未写原因；日报继续包含短素材，复用配置中的选题门槛。不调75默认门槛、7.5分钟间隔、当批轮转、事实门禁及重写预算，不批量改历史分数、状态、原因或文章，不新建队列。

## 当前合同

- Hermes选题分是短素材score，正常评估通过onlyIfPending+selectionScore和状态原子同步；通用基础补评、爆文常规及重评限定article，执行模型前防御性排除短素材。长文规则不变。
- 选题先去重，重复素材可能无分；低于实际配置门槛的原因含分数、门槛和真实评分理由。事实停止保留原证据冲突，质检用尽原预算保留最后反馈。
- worker停止用onlyIfWritable仅推进pending/ready/queued/writing，不覆盖人工终态。状态同步失败沿原技术恢复预算，不冒称平台已停止或重建任务。
- 短素材表格及详情明确选题分；跳过/失败下方用小字完整显示原因，无历史理由明确显示未记录，不推断。调度状态以 Hermes 为真源，队列任务优先于素材表可能滞后的 `ready`；候选、待确认、替换均通过 `source_external_id` 关联。实际队列位置与自动候选顺位分开显示，`ready` 本身不表示已入选；没有匹配记录时只说明当前未排入，不推断未来批次或历史去向。
- 短素材不显示爆文分/维度，不再提供爆文筛选，移除旧短页筛选偏好且不传隐藏门槛；长页显示和偏好保持。
- 短成品移除素材趋势，保留生成后质检评分。历史趋势字段不清空、不迁移数据库。
- 日报短素材复用short_content_score_threshold（默认75），不等待爆文评分；长素材沿用基础72/爆文50。日报日程和生成流程不变，不新增评分调用。
