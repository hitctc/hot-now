- 现有表格移动断点≤767px：主区数据表格共用屏宽和居中负外边距，抵消页面/卡片对称留白；内层宽表仍自行横向滚动。不改筛选、页头、正文Markdown表格或PC样式。四张创作表格手机首屏将ID列缩为56px，标题列使用剩余屏宽；同时按实际列宽之和设置表格总宽，避免固定布局将多余宽度重新分配到前两列。首列表头仅显示ID，隐藏第二行`#`序号，压缩首列内边距而不截断ID；素材表隐藏额外展开图标列，保留标题点击展开。窗口变化重新计算，卸载清理监听，其他列仍通过内部横滚查看；PC保留72px ID/序号列、300px标题列及原滚动宽度。
